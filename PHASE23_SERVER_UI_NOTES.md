# Phase 23 – Server / Serving Center UI Refinement

Turns the Server tab into a clearer serving center.

## Added

- Renamed Server section to **Serving Center**.
- KPI strip for configured profiles, running servers, HTTPS-required profiles, and Telegram-required profiles.
- Runtime summary explaining whether profiles are missing, stopped, or serving traffic.
- Serving checklist guidance strip.
- Better empty state with direct create-profile action.
- Subtle card styling for server profile cards.
- Regression test for serving center shell rendering.

## Scope

No schema changes and no server API contract changes. UI-only serving refinement.
