# Phase 19 – Monitor / Validation Center UI Refinement

Turns the Monitor tab into a clearer validation center.

## Added

- Renamed Monitor section heading to **Validation Center**.
- KPI strip for monitor profiles, running jobs, paused jobs, and targeted candidate pool.
- Runtime summary that explains whether monitors are idle, running, paused, or missing.
- Guidance strip showing the operational validation flow.
- Better empty state with direct create-profile action.
- Subtle card styling for monitor profile cards.
- Regression test for monitor center shell rendering.

## Scope

No schema changes and no monitor API contract changes. UI-only refinement.
